# proton-drafts-mcp

MCP server that creates draft emails in Proton Mail via [Proton Bridge](https://proton.me/mail/bridge) IMAP. Drafts appear in your Drafts folder in the Proton Mail web app and mobile apps.

Works with Claude Code, Claude Desktop, Cline, and any other MCP-compatible client.

## Requirements

- Proton Mail paid plan (Mail Plus, Unlimited, or Business — Bridge requires a paid plan)
- [Proton Bridge](https://proton.me/mail/bridge) installed, signed in, and running
- Node.js >= 18

## Install

```bash
npm install -g proton-drafts-mcp
```

Or run via `npx` (no install):

```bash
npx proton-drafts-mcp
```

## Add to Claude Code

User scope (available across all projects):

```bash
claude mcp add -s user proton-drafts -- npx -y proton-drafts-mcp
```

Or with a global install:

```bash
claude mcp add -s user proton-drafts -- proton-drafts-mcp
```

## First-run setup

On first call, the server detects no stored credentials and opens a browser window with a setup form. Enter:

- **IMAP host** — `127.0.0.1` (default Bridge address)
- **Port** — `1143` (STARTTLS) or `1993` (SSL/TLS)
- **TLS** — STARTTLS for port 1143, SSL/TLS for port 1993
- **Username** — your Proton email address
- **Bridge password** — auto-generated by Proton Bridge (NOT your Proton login password)

Find these values in Proton Bridge: open the Bridge app → click your account → **Mailbox details**.

Credentials are stored in **Windows Credential Manager** (or macOS Keychain / Linux secret-service) under service name `proton-drafts-mcp`. Never written to disk in plaintext.

## Tools

### `create_draft`

Create a draft email.

| Param | Type | Required | Description |
|-------|------|----------|-------------|
| `to` | string | yes | Recipient email(s), comma-separated |
| `subject` | string | yes | Subject line |
| `body` | string | yes | Body content |
| `isHtml` | boolean | no | If true, body is HTML (default false) |
| `cc` | string | no | CC recipient(s), comma-separated |
| `bcc` | string | no | BCC recipient(s), comma-separated |

### `reset_credentials`

Delete stored credentials. Next `create_draft` call re-triggers the browser setup flow.

## Why drafts (not direct send)?

Proton Bridge supports SMTP send too — but creating drafts means the email lands in your Drafts folder for human review before sending. Safer for AI-generated emails. Open Proton Mail, review, edit, click Send.

## Troubleshooting

**"Could not find Drafts mailbox"** — Bridge mailbox layout may differ. Open Bridge → Mailbox details → verify a `Drafts` folder exists in the IMAP listing.

**"Invalid login: 535"** — Bridge password incorrect. Re-copy from Bridge app and run `reset_credentials`.

**"ECONNREFUSED 127.0.0.1:1143"** — Proton Bridge not running. Launch it from the system tray.

**Browser doesn't open on first run** — Check stderr for the URL (`http://127.0.0.1:<port>/`) and open manually.
